# Predictive Maintenance Agent

## Problem Statement
Manufacturing equipment downtime can cause production delays,
financial losses, and reduced productivity. Machine operating data
can be analyzed to predict potential failures before they happen.

## Objective
Build a predictive maintenance agent that:
- Detects anomalies
- Predicts failure probability
- Identifies root causes
- Recommends maintenance actions
